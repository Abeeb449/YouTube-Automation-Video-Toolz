# Reference videos

Upload example videos (or screenshots) here whose style you want ytauto to copy.

**How to upload on GitHub:** open this folder → **Add file → Upload files** → drag the file in → **Commit changes**.

- A 1–2 minute clip is enough.
- Browser uploads are limited to **25 MB per file**. If a video is bigger, trim it or send screenshots instead.
- Screenshots (`.jpg` / `.png`) work too.

These files are only used as style references; they're not used in rendered videos.
